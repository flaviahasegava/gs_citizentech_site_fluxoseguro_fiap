# 💧 Fluxo Seguro - Sistema de Monitoramento Preditivo de Alagamentos
O **Fluxo Seguro** é um projeto desenvolvido para a avaliação **Global Solution FIAP (CitizenTech)**, com a proposta de **monitorar o nível da água em bueiros e emitir alertas para ajudar a prevenir acidentes causados por alagamentos**.


## 🔹 O que é CitizenTech?
- CitizenTech é o uso da tecnologia para resolver problemas da sociedade, melhorar os serviços e facilitar a vida das pessoas. A proposta é utilizar a inovação para gerar benefícios para a população
- No Fluxo Seguro, esse conceito aparece na criação de uma solução que ajuda a identificar riscos de alagamento e alertar as pessoas.


## 🔍 Sobre o projeto
Foi desenvolvido um site de página única para apresentar o Fluxo Seguro e compartilhar informações sobre sua proposta de prevenção de alagamentos. Durante a criação, colocamos em prática os conhecimentos adquiridos nas disciplinas de Front-end Design e Web Development, utilizando HTML, CSS e JavaScript para estruturar e desenvolver as páginas.


## 🎯 Objetivo
Oferecer aos usuários uma forma simples e acessível de conhecer o projeto Fluxo Seguro, entender como funciona a solução e conhecer sua importância na prevenção de alagamentos. O site foi pensado para facilitar a navegação, organizar as informações e proporcionar uma boa experiência ao usuário.

## ⚙️ Funcionalidades em JavaScript
- **Mensagem de boas-vindas:** ao abrir o site, um popup apresenta o projeto.
- **Nome do usuário:** popup para perguntar o nome do usuário, não aceita o campo vazio e exibe o nome na página inicial.
- **Slideshow dos alagamentos:** navegação entre as imagens de alagamentos por setas e bolinhas.
- **Formulário de contato:** valida se todos os campos foram preenchidos e mostra um alerta de sucesso ou de dados faltando, sem recarregar a página.
- **Formulário de sugestão:** funciona como o de contato e exige também a escolha do tipo (Melhoria ou Problema).
- **Confirmação ao limpar:** antes de apagar os dados de um formulário, é pedido uma confirmação.
- **Ano automático no rodapé:** o ano é atualizado sozinho com a data do computador.
